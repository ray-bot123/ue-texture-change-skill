# 空间结构控制工作流

可选扩展，尚未实测。仅在用户明确选择结构控制且已提供或授权接入后端时读取。此文定义能力要求，不代表已有可运行的 ComfyUI JSON 工作流。

## 输入与对齐

保留原主图、获批 texture、确认的单通道遮罩和分区说明。彩色编号预览图不等于实际 inpaint mask；分别保存实体投影区、镜面区、地面光影联动区和保持区。已有手绘或自动推断边缘是近似值，不称为精确 Object ID；对细圆片、杆件及遮挡边缘进行必要修正。

所有输入使用同一相机和像素坐标。模型需要 8/16/64 等倍数尺寸时按实际后端要求统一 padding，记录四边补齐量，生成后精确去 padding；不得各自居中裁切或改变纵横比例。控制图、遮罩和主图必须使用同一变换。预览图附加的图例栏不得进入渲染输入。

## 结构条件

- 从实体分区轮廓和主渲染图中的可见结构构建干净边缘控制图。排除原纹理的叶片、条纹和花纹细节，否则旧纹理也可能被固定。不要把全部 Canny 边缘无差别作为建筑结构。
- 从主渲染图保留镜中物体的可见边缘、圆片群轮廓和遮挡顺序。普通 UE 深度/法线描述镜面平面，不能替代镜中几何；不将其误用于镜后柱子的三维控制。
- Depth/Normal 是可选的补充控制。必须查明所用 ControlNet 对编码、坐标空间、轴向、通道顺序、范围及预处理的要求。UE 法线图不能未经验证直接当成通用 Normal 条件；Depth 也不能仅因看起来像灰度图就判定可用。
- 控制模型须与基础生成模型相容。实际工作流支持多控制时可组合边缘和深度/法线；不能假定每个模型都支持同样的控制器。

## 真实执行与合成

1. 查询后端实际能力，核对基础模型、控制权重及必需节点已加载可用。确认 img2img/inpaint、控制图、mask 和最终合成的真实输入连接。不能把文件作为普通参考附件后称为结构控制。
2. 固定种子、尺寸和初始基线，记录控制强度、控制起止、重绘强度和采样参数。数值按具体后端及模型调整，不设通用“保证锁定”值。较低重绘强度可能保留旧纹理；较高值可能改变结构，需权衡验证。
3. 优先采用已经批准的素材作为实际变形/贴图合成源，模型只细化必要的光影或接缝。若仅用图像参考适配器引导外观，应明确它不保证逐图案复刻，不得称为原 texture 直接贴入。
4. inpaint mask 限制生成范围不等于保护区输出像素绝对不变。生成后以原图和明确的最终 alpha mask 做确定性合成；镜面和地面反光若允许修改，必须在联动区域中单列。
5. 不用整面镜子的宽泛遮罩来替代反射物体的结构控制。镜面内仍须对照原有反射轮廓；不新增反射实体。AI 联动结果不宣称物理精确。
6. 出图后恢复原始分辨率并验收；只有通过后才称为最终效果图。每次默认只生成一张。

## 验证与停止条件

- 输入输出画幅一致；不得通过任意拉伸输出掩盖构图漂移。
- 保护区通过最终合成保持原图像素；允许羽化的过渡范围须明确，不可侵入邻近结构。
- 在同一坐标系叠加获批轮廓，检查柱体顶部、底部、最窄处、两侧位置、圆片大小、杆件和镜像对应。测量需基于真实几何边缘；亮花纹产生的视觉边缘不计为结构。
- 外边界合成不能保证区域内部几何不变，也不能修复错误遮挡。保持区像素一致并不足以单独通过几何验收。
- 明显错误先诊断链路；无可修复原因就停止重抽，保存对比图和失败原因。后端未接入时停止在素材阶段，不能退回无控制整图生成消耗额度。

## 项目记录

保存后端类型/版本、基础模型、控制模型与文件、单通道 mask、素材路径、用户确认状态、种子、关键参数、尺寸变换、合成方法与验收结果。已有批准在内容未改变时继续有效。不要把工作流“计划配置”写成“已运行验证”。
